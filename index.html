角色顾问

纯静态、可自托管的 AI 对话工作台。自己配知识库和角色提示词，密钥只存在你本地浏览器，不经过任何服务器。

1 配置 API 密钥 必填

用你自己的密钥，浏览器直连大模型。支持 DeepSeek / OpenAI / Moonshot 等允许跨域的接口。密钥只存在本机，不会被上传。

2 创建你的角色 自定义

先点「自定义」从空白建，或点下面两个示例——《华为基本法》《蓝军参谋部》，点一下下方表单就自动填好（名称 / 提示词 / 知识库勾选），改完再创建。示例已自带对应知识库与提示词。需要你自己的资料？在「挂接知识库」里点「＋ 上传本地资料」上传 .md/.txt 文件，或点「＋ 添加网址」直接粘贴 GitHub / 可跨域网址（如 raw.githubusercontent.com/.../x.md），抓取后自动归到你名下并可勾选。

设置

① API 配置只存本地

模型接口必须允许浏览器跨域（CORS）。DeepSeek / OpenAI / Moonshot 等均支持。密钥仅用于你本机发起的请求。

② 角色管理

默认角色来自仓库 presets/advisors.json；下面可新增 / 编辑 / 删除你自己的角色（存本地）。

③ 知识库管理

默认知识库是仓库里的 .md 文件（可 fork 后增改）；下方可添加你自己的资料（存本地，不上传）。

支持任何可跨域网址（GitHub raw 链接最稳）。若抓取失败，多半是该网址不允许跨域（CORS），改用本地粘贴或上传即可。
